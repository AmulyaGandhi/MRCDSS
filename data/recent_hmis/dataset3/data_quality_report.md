## 2. Missingness by feature

Missing values are NOT imputed. A missing cell means the underlying HMIS count was blank
(suppressed/not reported) or the item is structurally absent for that schema (obstetric complications
from 2023-24 onward).

| Feature | Valid | Missing | Missing % |
|---|---|---|---|
| ANC_First_Trimester_Pct | 3,148 | 158 | 4.8% |
| TT2_Booster_Pct | 3,148 | 158 | 4.8% |

| Obstetric_Complications_Pct | 2,219 | 1,087 | 32.9% |

Obstetric missingness includes 951 structural NaN rows for 2023-2024 (783) and 2024-2025 (168) where the

Pradesh 2020-21 new districts, Rajasthan's new districts across 2020-21 .. 2023-24).

*\*2024-2025 includes only the 17 states with acquired UpTo_Mar files; the 565 "missing" are reference

Across all five years **0** of the 707 reference units are absent (the 20 in 2022-23 are temporarily
renamed/reorganised units that return by 2023-24). 105 new units exist that are not in the legacy 707
(e.g. Andhra Pradesh's 2022-23 districts Anakapalli, Annamayya, Bapatla, ...; new Rajasthan districts;
new Chhattisgarh districts). State + District remains the unique key - districts with the same name in
different states are never collapsed.

## 9. Structural and parsing notes

- All values use the district **Total** sub-column. Inspection verified Total == Public + Private ==
  Urban + Rural (0 mismatches) and state total == sum of district totals (0 mismatches) on inspected files.
- Non-numeric cells in the raw files are exclusively blank strings - no '-', 'NA' or '<' suppression
  markers exist. Blanks are preserved as NaN.
- Negative counts exist only in vaccine/stock modules (Modules 17-20) and are irrelevant to the four
  analysed indicators.
- Raw files are marked "Provisional Figures"; several carry a later "Status As On" date (retroactive
  updating). Values are cumulative as of the file's coverage month.
